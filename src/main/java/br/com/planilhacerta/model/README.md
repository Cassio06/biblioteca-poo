# Pacote `model`

Espaço reservado para as classes de domínio e enumerações do sistema **Planilha Certa**:
- `Pessoa` (abstrata), `Cliente` (abstrata), `ClienteRegular`, `ClienteVIP`
- `Consultor`, `Especializacao` (`FINANCEIRO`, `GESTAO`, `TI`)
- `Contrato`, `ModalidadePagamento` (`POR_ETAPA`, `ENTREGA_FINAL`)
- `Projeto`, `Etapa`, `StatusEtapa` (`PENDENTE`, `EM_ANDAMENTO`, `CONCLUIDA`, `ATRASADA`)
- `Fatura`, `RelatorioDesempenho`
