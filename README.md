# Biblioteca POO

Sistema de gerenciamento de biblioteca em Java, desenvolvido como projeto acadêmico da disciplina de Programação Orientada a Objetos.

## Objetivo

Organizar o acervo e controlar empréstimos e devoluções, acompanhando a disponibilidade dos livros, os prazos e as multas por atraso.

## Status

Projeto em planejamento e desenvolvimento inicial. As funcionalidades abaixo representam o escopo previsto e ainda não estão confirmadas como implementadas.

## Funcionalidades planejadas

- Cadastrar, consultar, editar e remover livros e usuários, respeitando os vínculos com empréstimos.
- Consultar a disponibilidade dos exemplares.
- Registrar empréstimos e definir datas de devolução.
- Registrar devoluções e atualizar a disponibilidade.
- Calcular multas por atraso conforme as regras definidas pelo grupo.
- Consultar empréstimos ativos e histórico de empréstimos.
- Gerar relatórios de disponibilidade, empréstimos e atrasos.
- Salvar e recuperar dados em arquivos.
- Tratar entradas inválidas e arquivos ausentes sem interromper o fluxo principal.

## Programação Orientada a Objetos

O projeto deverá aplicar os seguintes princípios de forma justificada:

- **Encapsulamento:** proteger os dados e validar alterações por meio dos métodos das classes.
- **Abstração:** representar os elementos do domínio, como usuários, livros, exemplares e empréstimos.
- **Herança:** compartilhar características entre tipos que possuam uma relação adequada no domínio.
- **Polimorfismo:** permitir comportamentos específicos entre esses tipos, como regras de empréstimo para diferentes categorias de usuários.

A modelagem definitiva será acordada pelo grupo antes da implementação.

## Tecnologias e decisões

- **Linguagem:** Java.
- **Persistência exigida:** arquivos CSV, JSON ou TXT; o formato será definido pelo grupo.
- **Interface proposta:** console, para concentrar o desenvolvimento nas regras do sistema e nos conceitos de POO.
- **Testes planejados:** empréstimos, devoluções, disponibilidade, cálculo de multas e validações.

A versão do Java, a ferramenta de build e as bibliotecas serão documentadas após a configuração do projeto.
